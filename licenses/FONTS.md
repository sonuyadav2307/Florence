# Font licenses

Florence self-hosts Inter and Cormorant Garamond through `next/font/google` at build time.

- Inter: SIL Open Font License 1.1 — https://github.com/rsms/inter/blob/master/LICENSE.txt
- Cormorant Garamond: SIL Open Font License 1.1 — https://github.com/CatharsisFonts/Cormorant/blob/master/OFL.txt

If hosted font files fail, the UI falls back to system sans-serif and Georgia.
